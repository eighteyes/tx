## Your task

Read the document specified below. If it's a file path, use Read. If it's a URL, use WebFetch. Then produce four sections.

**Document:** $ARGUMENTS

### 1. Non-Obvious Insights (3-5)

Identify things that aren't stated explicitly but can be inferred from the content. Skip anything the author already highlights as a key point. Look for:
- Unstated assumptions that reveal the author's mental model
- Implications the author may not have noticed
- Patterns that emerge across sections but aren't called out

### 2. Tensions and Contradictions

Where does the argument conflict with itself, or with conventional wisdom? What's left unresolved? Name the specific passages or ideas that pull in opposite directions.

### 3. The "So What"

If a smart, busy person could only take away one actionable implication from this, what would it be and why? State it as a concrete action, not an abstract principle.

### 4. What's Missing

What question does this document raise but never answer? What would you want to know next? Name the gap that matters most.

## Constraints

- Prefer inference over summary. Restating what's already written earns zero points.
- Be specific. Cite sections, quotes, or structural choices — not vibes.
- Each insight should be one sentence of claim followed by one sentence of evidence.
